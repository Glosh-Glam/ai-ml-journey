# Project 5: Atlas capstone (Weeks 15–16)

**Brief:** One SaaS dashboard where Pulse, CareScribe, and Resolve ship as features of a single product.

## Deliverables
- [ ] `FEATURES.md`: for each feature, deterministic or generative AI, with value, cost/latency, and risk (W15)
- [ ] Dashboard (Streamlit or Next.js) that calls all three services (W15)
- [ ] Deployed publicly (AWS or a free host), with secrets in env vars only (W16)
- [ ] Top-level portfolio README: hero section, architecture diagram, 3-min demo video, resume bullets (W16)

## Done when
A stranger can open the URL, use all three features, and understand from the README what you built and why.
